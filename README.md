
# CogniStream

Developer Flow-State & Cognitive Load Analytics.

## Project Goal
Analyze simulated developer activity to understand coding focus time, interruptions, and context switching.

## Technologies
- Python
- ClickHouse
- Polars
- Apache Airflow
- FastAPI
- React

## Current Progress
- Generated mock developer activity using Python.
- Exported events to CSV and JSON.
- Set up ClickHouse using Docker.
- Created an activity events table.

## Project Structure
- `scripts/` — Python scripts
- `data/` — Sample activity data
- `requirements.txt` — Python dependencies

## Status
Under development.
